V4

Metronome / Beat Pacing

Tempo as a felt rhythm: a pendulum swings on the target cadence (the beat you match); a pulse fires each phase boundary; a ghost bar is where you should be, the solid bar is where you are. Highest ceiling, most novel.

Degrades to poll: most poll-robust — the target beat is client-side (target is static) so the pendulum never stutters; only the actual tracker gets steppy. Conveys rhythm well but exact seconds/velocity poorly — pair with a numeric readout.

All four loop a rep every 5s. Fill windows map the real timeline: CON 0–1.0s, HOLD 1.0–1.2s, ECC 1.2–4.1s (of the 3-0-1 on-pace rep). Pace coloring uses getPacingState — behind triggers at elapsed/target > 1.15. Velocity band colors are the SHARED-BRIEF 4-band scale (green fastest). No external deps; renders standalone via file://.
