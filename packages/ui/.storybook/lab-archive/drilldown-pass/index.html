DIRECTION A

Persistent rail + focus stage

288px always-visible session skeleton (every exercise × set, live position marker) anchors the wall; one large stage re-targets between levels in place with a 150ms crossfade — never a page slide. Rail keeps a mini live-pill during drills; ~9s idle auto-returns the stage to live.

Signature: you never lose your place — the rail is the map and the back button.
DIRECTION B

One canvas, expand in place

No navigation at all: a fixed-column masonry canvas where levels grow inside the cards that own them (card → set table → strip → bars → rep tooltip), the active-workout ladder at wall scale. Sticky color-flooded hero lane keeps live primacy; expansion only ever pushes down-column.

Signature: one transition vocabulary — everything is the strip-to-bars ease at different scales.
DIRECTION C

Master/detail columns

Adjacent levels get adjacent columns; drilling slides a child column in while ancestors compress to 86px clickable spines — context never leaves the screen, and level-skips animate through the intervening columns so distance stays legible. Pinned anchors (hero, body map) never compress.

Signature: passive and interactive are the same widget — columns collapse to a single live hero and re-expand.
DIRECTION D

Immutable glance + overlay drill

The passive layout never changes — every drill is an overlay over a spotlight scrim that keeps the live hero readable, with a persistent live strip pinned above it. Lineage drills replace within one breadcrumbed panel; lateral peeks stack one side-sheet. Idle timeout self-heals to pure glance.

Signature: the across-the-room contract is sacred — same pixels all session.
