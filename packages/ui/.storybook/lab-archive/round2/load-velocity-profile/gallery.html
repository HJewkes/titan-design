Same encoding, three data shapes. Band width & tint tell you how far to trust the crossing.
Why this leads: the operator called the CIs necessary. R1 rendered it on one tight cluster so the band read as a blob. Here the band is the figure: it hugs a clean fit (crisp e1RM), flares in the extrapolation where a flattening profile is being stretched past its data, and balloons on sparse/noisy data so the e1RM is an honest ≥-range, not a false number. Band tint doubles as a trust signal (teal → amber → red). The middle case also shows the string confidence enum can read "high" while the geometry (curving points + flaring band) says "careful" — the band sees what the enum can't.
V1Classic scatter — overlap fixed, per-set variability added
What changed from R1

Overlap fixed. R1's e1RM ring, its label and the grinding-end dots collided at the bottom-right. Now the e1RM marker sits on the MVT line with a short leader line to an offset pill, and the crowded per-point value labels are gone — dots are colored by velocity band instead, so density reads without text.

Variability added. Each point now carries a ±1 SD whisker from the set's individual rep velocities (the raw reps that average into the mean-concentric point), and a thin steel prediction band wraps the fit. The grind end is visibly noisier — you can see the data getting less certain exactly where the e1RM extrapolation begins.
